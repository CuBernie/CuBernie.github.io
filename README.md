Open [index.html](index.html) in a web browser. No installation or local server is required.

## Publish with GitHub Pages

1. Create a GitHub repository, or use an existing one.
2. Upload `index.html` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the branch containing the files (usually `main`) and the **/ (root)** folder, then select **Save**.
6. Wait for deployment to complete, then open the site URL shown in the Pages settings.

A repository named `<username>.github.io` can serve as your account’s main homepage. A repository with another name is normally published under `https://<username>.github.io/<repository>/`.

## Customize
